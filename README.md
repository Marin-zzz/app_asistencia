# app_asistencia
-ionic CLI 7.2.1 <br>
-angular CLI 19.2.12 <br>

Para iniciar en local<br>
-npm install <br>
-ionic serve <br>

Para iniciar en andoid estudio (despues de npm install)<br>
-npx cap add android<br>
-hacer cambios correspondientes en android\app\src\main\AndroidManifest.xml <br>
-hacer cambios correspondientes en android\variables.gradle <br>
-ionic build <br>
-npx cap sync <br>
-npx cap open android <br>
